
# Project Requirements

## Basic Encryption and Decryption

### Objective
To implement a basic encryption and decryption program using the Caesar Cipher technique.

### Requirements
1. Accept text from the user.
2. Accept a numerical shift key.
3. Encrypt the text using the Caesar Cipher.
4. Decrypt the encrypted text using the same key.
5. Display the original, encrypted and decrypted text.

### Concepts Used
- String handling
- ASCII character conversion
- Conditional statements
- Loops
- Shift keys
- Modular arithmetic
