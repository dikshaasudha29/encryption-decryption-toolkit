
# Basic Encryption and Decryption Tool

## Overview
A simple Python project that implements encryption and decryption using the Caesar Cipher technique.

## Features
- Accepts user input.
- Encrypts text using a numerical shift key.
- Decrypts the encrypted message.
- Preserves spaces, punctuation and letter case.

## Technology Used
- Python

## How to Run

```bash
python src/encryption.py
```

## Encryption Technique
The project uses the Caesar Cipher, which shifts alphabetic characters by a fixed number of positions.
